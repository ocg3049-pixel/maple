## 1. 한 줄 컨셉
> "토글 한 번이면 캐릭터가 스스로 몬스터를 찾아 이동하고 스킬로 사냥한다 — 방치 성장 루프(자동사냥 → 메소 → 강화 → 레벨 → 상위 사냥터)의 마지막 조각."

## 3. 코어 루프
```
F7 ON → 최근접 몬스터 탐색 → 좌우 이동 접근 → 사거리 도달 → Q 스킬 반복 시전
  → 처치 → 메소 흡수 → 다음 몬스터 → (몬스터 없음: 정지 대기 / 리젠 대기)
```

## 4. 핵심 시스템
- **AutoHuntManager (@Logic, ClientOnly 중심)**: 토글 상태, 0.3초 주기 대상 탐색 캐시, OnUpdate 이동/공격 판단. 사망(DEAD) 중 일시정지, 맵 이동 시 자동 재탐색.
- 공격 사거리: 접근 종료 유클리드 **1.15**, 시전 게이트 **1.3**(같은 층 `|dy|<1.2`일 때만). 공격 틱 **0.5초**(각성 중에는 공속 비례 0.12까지 축소). 실쿨은 SkillManager가 관리.
- 추적 타임아웃: 같은 대상을 5초 넘게 못 때리면 3초간 제외(다른 발판 몬스터에 갇힘 방지).
- **전방 박스 정합**: 서버 실판정은 `dx * dirX >= 0`(전방 박스)이므로, 대상이 바라보는 방향 반대편이면 **크기와 무관하게 방향을 먼저 돌린다**(불감대는 이미 앞쪽일 때만).
- **지형 판정 공용 규칙**: `PredictFootholdEnd(d, dir)`는 **"그 거리만큼 갈 수 있으면 true"** (발판 끝 감지가 아니다 — 극성 반대). 벽/절벽 구분은 진행 방향 앞에서 위로 쏘는 `FootholdComponent:Raycast`로 한다.

## 6. 로드맵 (Phases)
### Phase 1 — "F7 켜면 알아서 사냥한다" (지능형 확장 포함)
- ✅ AutoHuntManager 신설 — F7 토글·토스트·사망 일시정지·맵 이동 시 자동 재탐색 (`AutoHunt/AutoHuntManager.mlua`)
- ✅ 추적·이동 — 같은 높이 우선 최근접, 5초 타임아웃 제외, 자동 이동 중 PlayerController 비활성(정지/OFF 복구), **걷기 모션 = ChangeState("MOVE")** (WALK는 미등록·LEA-3005), 위/아래 발판은 점프/다운점프 추적, **공격 방향 = `LookDirectionX` 직접 대입**(스킬 판정·모션·이펙트가 전부 이 값을 읽음 — "짧은 이동" 방식은 무효였음. 검증: dx=-0.62→look=-1.0 / dx=2.96→look=1.0 정합)
- ✅ 스킬 용도별 로테이션 (사용자 피드백 확장) — 스킬바 전체 스캔 → 버프(스킬별 주기: 콤보 어택 25분·기타 4.5분, ON 직후 즉시 1회)/소환수(290초)/공격 **가중 랜덤**: 다수(사거리권 2마리↑) 시 광역 가중 3.0·단일 0.4, **브랜디쉬 보유 시 파워스트라이크·슬래시블러스트 1% 강등**, **전방 3유닛 직선상 2마리↑면 돌진 ×5**. 검증: 돌진 27/브랜디쉬 17/코마 7/패닉 6/파스·슬블 0회(1% 정상), 에러 0
- 🟡 통합 검증 — 로그 검증 완료. ⚠️ needs user test: ① 장시간 방치 체감(처치/시간 실측 — 커브 재보정 데이터) ② 모션이 버튼 조작과 동일하게 보이는지 육안 ③ F7 OFF 후 수동 조작 복귀 ④ 발판 점프 추적 체감
### Phase 2 — "발판을 넘어다닌다"
- 🟡 위/아래 발판 내비게이션 개선 — 수평 정렬(위 |dx|≤1.2 / 아래 |dx|≤1.5) 후에만 점프/다운점프. ⚠️ needs user test: 발판 많은 사냥터(hunting 지역)에서 체감
- ✅ 몬스터 전멸 시 배회 — 검증: 빈 로비(hunting01)에서 걷기/대기 교대·좌우 방향 전환 로그, 리젠 감지는 0.3초 스캔으로 자동 복귀
- ✅ 자동 HP 포션 — 검증: HP 18/70(26%) 감지 → 자동 사용 → 힐 5틱 진행 (28→38→48…), 힐 중 재사용 방지
### Phase 3 — "어떤 지형·어떤 직업이든 스스로 사냥한다" (2026-08-10 정합화로 신설 — 08-04~08-10 구현분)
- 🟡 지형 판정 기반 재정립 — `PredictFootholdEnd` **극성 오류 수정**(배회가 지형 한가운데서 "양쪽 다 막힘"으로 얼어붙고, 진짜 발판 끝에서는 걸어 떨어지던 원인). 실측표: 가운데 R/L 모두 true, 좌우 끝에서 해당 방향만 false. ⚠️ needs user test: 무대상 배회 동선 체감
- 🟡 벽·턱 앞점프 등반 — `TryStepUpOverWall`(진행 방향 지면이 끊겼고 앞 0.5유닛 위로 올라설 발판이 점프 사거리 안이면 점프). 추적·배회·**로프 접근** 3경로 적용. 실측: 0.60 턱에서 6초+ 정체 → 0.8초 만에 등반. ⚠️ needs user test: 여러 사냥터의 다양한 턱
- 🟡 로프(사다리) 등반 — `GetRopes`/`FindUsableRope`/`RopeClimbTick`. 앞점프로 못 닿는 위층 전용. **부착 실패 조기 종료**(점프 후 1.2초 안에 CLIMB 미진입 시 즉시 취소 — 없으면 `ropeUntil`(6+거리×1.2+dy×1.5 ≒ 10~15초)까지 완전 정지). ⚠️ needs user test: 로프 많은 사냥터
- 🟡 등반 직후 동선 안정화 — 하강 1.2초 보류 + **3초 층 고정**(FindTarget이 발 높이 ±0.4 적만 후보로 봄 · 발판 끝 방향으로 걸어 나가지 않음). 앞점프·벽 앞점프·로프 도착 3경로. 실측: 착지→하강 0.4초 → 3.0/3.0/>15초. ⚠️ needs user test: 둔덕/사다리 구간 체감
- 🟡 위층 도달 가능성 사전 판정 — `CanReachTargetLayer`(대상이 **실제로 선 발판**까지 한 번에 올라설 수 있는지: 사거리 + 중간 발판 차단 여부). 불가 시 `IsTargetLayerUnreachable` 확인 후 즉시 6초 제외. 두 층 위 대상에 올라갔다 내려오기를 2~3회 반복하던 문제. ⚠️ needs user test: 좌측 위 다층 구간
- 🟡 대상 재선정 안정화 — **대상 잠금 5초**(살아 있으면 재타겟 금지, 죽으면 즉시) + 잠금 해제 후 **뒤쪽 후보 거부**. 실측: 대상 변경 6회 전부 직전 `Monster: Dead()`. ⚠️ needs user test: 리젠 잦은 구간 동선
- 🟡 러시(질주) 발판 이탈 방지 — 시작 게이트(진행 방향 2유닛 이상 지면) + 주행 감시(앞 0.7유닛 끊기면 `EndSprint`). ⚠️ needs user test: 짧은 발판에서 질주 낙하 여부
- 🟡 전방 박스 헛방 수정 — 방향 보정 불감대(0.05)가 "0.03유닛 뒤" 대상에 대해 방향을 안 고쳐 `targets=0` 시전이 반복되던 문제. 대상이 반대편이면 무조건 선회. 실측: 브랜디쉬 targets=0 **22%(2/9) → 0%(0/10)**. ⚠️ needs user test: 파스/슬블/브랜디쉬 헛방 체감
- 🟡 직업별 자동사냥 로테이션 9종 — 팔라딘(속성 연계 선설치·자동 가드)·신궁(스나이핑/피어싱 차지)·보우마스터·나이트로드(각성 제자리 사냥)·섀도어(다크사이트 잠복·연막 저격)·썬콜(오로라 난사)·불독(포이즌 카펫)·비숍·다크나이트(드래곤 라이딩 비행 이동). ⚠️ needs user test: 직업별 관전 체감
- 🟡 히어로 3차 코마/패닉 전용 규칙 — 코마 = 구슬 모아 넓게(범위 = 구슬 비례), 패닉 = 남은 HP ≥ 전투력×5인 탱커 전용. 실측: 코마 0회 → 구슬 4/5·±7.0에서 15마리 상한 적중. ⚠️ needs user test: 코마 사용 빈도 체감

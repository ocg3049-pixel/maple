# MapleIdle 밸런스 워크시트 (직업 간 DPS · 몬스터 HP)

> AI 노트: 이 문서는 밸런싱 반복 작업의 진실의 원천이다. 스킬 배율을 코드에서 바꿀 때마다
> §2 표의 해당 행을 갱신하고, 실측값은 §4에 기록한다. GDD의 마일스톤 체크리스트와는 별개의
> 상시 작업 문서(로드맵의 밸런스 항목이 이 문서를 가리킨다).

작성: 2026-08-09 · 기준 커밋: 전투분석 창(F8)·허수아비 구현 직후

## 0. 목표와 판정 기준

- **상대 밸런스**: 동일 전투력·동일 사냥터에서 직업 간 처치 속도(kills/min) 편차 **±15% 이내**.
  단, "사냥 특화 vs 보스 특화" 축 분화는 의도된 개성으로 허용 — 한 직업이 두 축 모두 최하위인 것만 금지.
- **절대 밸런스(몬스터 HP)**: 적정 스펙에서 주력 스킬 **1~2방 컷** (§3 공식).
- 판단 순서: **① 이론표로 자릿수 오류 제거 → ② 실측(kills/min·허수아비 DPS)으로 수렴 → ③ 몬스터 HP 확정**.

## 1. 측정 프로토콜 (전투분석 창 사용)

1. 대상 직업 캐릭터를 동일 전투력 장비로 세팅 (22성 6부위 기본 지급 상태 = 기준 CP).
   **기준 CP 실측(2026-08-09, 신궁 테스트 캐릭터)**: 장비 총합 769 → 전투력 591,361 → 표시레벨 109.
   ⚠ **스킬 데미지의 CP = 제곱 후 전투력** — 실측 확인(40~60% 기본공격 배율 적중). 배율 1.0 = 전투력 값.
   ⚠ **측정 시점 주의**: 입장 직후엔 스킬 데이터 로드 전이라 769가 나오지만, 스킬 투자 보너스가 실리면
   실효 총합 1577(전투력 2,486,929)까지 올라간다(서버 캐시 실측). **직업 간 비교 실측은 반드시
   `/lv <레벨>` 명령으로 전투력을 고정하고 할 것** — (7L)²으로 정확히 통일된다.
   - `/lv` 명령(2026-08-09 신설, TestTools/TestCommandManager): 채팅에 `/lv 50` → 레벨 50·전투력 (350)²
     오버라이드(세션 한정, 저장 무영향), `/lv 0` → 해제. 기본공격 실측으로 서버 연동까지 검증 완료.
2. **사냥 축**: monsterzone(또는 대표 사냥터)에서 F8 → 측정시작 → F7 자동사냥 5분 → 측정종료.
   기록: 마릿수(kills/min), 총합 데미지.
3. **보스 축**: "허수아비 생성" 아이템으로 허수아비 소환(HP 1억) → 측정시작 → 수동/자동 딜 2분 → 측정종료.
   기록: 총합 데미지 ÷ 시간 = DPS.
4. §4 표에 기록. 기준 직업은 **히어로**(밸런스 프레임워크 기준 직업).

⚠ 주의: 새 투사체/소환수 스킬을 추가하면 `BattleStatsManager.OwnerComponentNames()`에 등록해야 집계된다.

## 2. 직업별 스킬 이론 DPS (코드 추출)

> 기대배율 = (min+max)/2. 크리티컬은 기본 크확 10%·크뎀 +25% 기준 기대 보정 ×1.025 (전 직업 공통이라
> 상대 비교에선 생략 가능 — 크확/크뎀 증가 스킬 보유 직업만 별도 보정).
> DPS 지표 = 기대배율 × 타수 × (시전주기)⁻¹, 단일 축은 대상 1, 광역 축은 대상수 상한 반영.

### 2.4 코드 추출 중 발견된 밸런스/버그 이슈 (2026-08-09 처리 완료)

1. ✅ **기본 공격 CP 무관 고정 50** → 서버 동기화 전투력의 40%~60%로 스케일(1차 스킬의 1/3 수준).
   실측 검증: 전투력 591,361에서 25.2만~39.4만(크리 포함) 적중. 동기화 전/미지 태그는 50 유지.
2. ↩ **비버그 재판정** — curse 장판은 매 틱 자기 전투력을 필드에 갱신 직후 판정(공유가 의도된 설계, 주석 명시).
3. ✅ **brandish.finish 크리 이중 적용** → CalcCritical isManualSkin 목록에 추가(두 목록 동기 주석 포함).
4. ✅ **math.random() 잔존** → rush/powerstrike/slashblast/.final 2곳(총 6개 호출) 전부 RandomDouble로 교체.
5. ↩ **실질 무영향 재판정** — 콤보는 히어로 전용 버프인데 히어로에겐 소환수·도트가 없어 발생 경로 없음(수정 보류).
6. ✅ **주석 정정** — slashblast 30%→50%, powerstrike 상한 250% 명시, strafe 200%→300%+, meteor 15개→20개.
7. ⚠ **파생 계보 드리프트(2026-08-09 발생, 미해결)** — powerstrike 0.5/2.5 리터럴이 도적 전 계보의 뿌리였는데,
   08-09 개편으로 **파워스트라이크만** 레벨 비례 곡선으로 바뀌었다. 아래 스킬들은 여전히 **옛 0.5/2.5를
   하드코딩한 자체 리터럴**을 쓰므로 "파워스트라이크의 1/3" 관계가 깨졌다(툴팁·카탈로그 desc도 옛 관계를 명시 중):
   - 럭키세븐 `GetLuckySevenRateMin/Max` = `0.5/3.0`, `2.5/3.0` (SkillManager)
   - 더블샷 / 더블스탭 / 매직클로 / 에로우 블로우 (럭키세븐·슬래시블러스트 계수 파생)
   비율을 되살리려면 이들도 레벨 비례로 함께 옮겨야 한다 — **다음 밸런스 작업 1순위**.

## 3. 몬스터 HP 공식 (직업 밸런스 수렴 후 확정)

- 적정 레벨 L 유저의 전투력총합 ≈ 7L, **스킬이 쓰는 전투력 = (7L)²** (제곱 후 값 — §1 실측 확인).
- **몬스터HP(L) = (7L)² × 주력스킬 기대배율 × 목표 타수(1~2)**.
  예: L=30 적정 → 44,100 × 배율. L=70 → 240,100 × 배율. (현행 일괄 3000은 전 구간 원킬 수준.)
- 레벨 밴드: 1차 10~29 / 2차 30~69 / 3차 70~119 / 4차 120+ (몬스터 스펙은 전 지역 동일,
  지역차는 메소 드랍뿐 — 기존 확정 사항 유지).
- ✅ **적용 완료(2026-08-09)**: `Balance/MonsterHpTable.csv`(L1~200) + `RegionTierLogic.GetMonsterHpForLevel`
  (CSV 우선·공식 폴백) + `Monster.OnBeginPlay`(MaxHp 기본값 3000 센티널일 때만 MonsterLevel로 유도,
  명시값은 존중 — 허수아비 1억 유지 검증). m(L) 앵커: (1,1.2)(10,1.5)(29~30,2.5)(69~70,5)(119~120,10)(200,16).
  실측: 필드 몬스터 89마리 전원 L15→29,158 적용, CSV 로드 로그 확인, 에러 0.
- 남은 일: 현재 전 몬스터가 MonsterLevel 기본값 15 — **몬스터 70종 티어 배정 작업에서 종류별 레벨 부여**
  (맵/모델에 MonsterLevel만 지정하면 HP는 자동). 적정 레벨 실전 체감(1~2방)은 저레벨 캐릭터로 실측 필요.

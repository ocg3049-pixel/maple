# 발도술 시전 이펙트 (금빛 재색상 업로드)

원본은 MSW 라이브러리 클립 2종. 사용자가 "브랜디쉬 이펙트와 비슷한 색"을 요청했는데, 원본이 청록빛이라
곱연산 틴트로는 광채 가장자리에 초록 잔상이 남아(실측) **원본 아트 자체를 색상 회전(청록 0.50 → 금빛 0.115,
채도 ×1.15)해 재업로드**했다.

## 정렬 방식 (중요)

- 원본 프레임 스프라이트는 크기가 제각각이고 피벗 메타데이터가 API에 없다.
- 대신 **리소스 검색 CDN의 애니메이션 GIF(공통 캔버스 320×240에 프레임이 정렬돼 있음)** 에
  각 프레임 PNG를 **교차상관(FFT SSD) 매칭**해 프레임별 오프셋을 복원, 320×240 공통 캔버스에 합성했다.
- 그래서 모든 업로드 프레임이 같은 캔버스·같은 정렬 → `MakeConstantFrames` 단일 고정 위치 재생으로
  흔들림 없이 원본 모션(검이 솟는 애니메이션)이 유지된다.
- 배치: head 캔버스 중심 = 발끝 +1.0 (검이 모자 위에서 솟음), foot 캔버스 중심 = 발끝 +0.15.
- 원본/합성본: `원본/` (재색상 전 정렬 합성본), `gold/` (업로드본). 작업 스크립트는 세션 스크래치에서 수행.

## 스킬/버프바 아이콘

- **현재 사용: `batto_icon_gold` = `400e3fc62cfe4860ad4385bec2dbf826`** — gold/icon.png (head_11 캔버스에서
  내용 bbox(92,22)+136×140만 크롭해 여백 없이 아이콘화). 스킬창 카탈로그 + 버프바 BattojutsuIcon에 적용.
- 저장된 퀵슬롯은 저장 당시 ruid를 들고 있어, ImportHotkeys가 **이름으로 카탈로그 최신 ruid를 재해석**하도록
  개선함(카탈로그에 없는 항목은 저장값 유지) - 이후 어떤 스킬이든 아이콘 교체가 재접속 시 자동 반영된다.
- 구버전(청록 원본) 아이콘: 클립 11번 프레임 `38abde2437a8407e949669035fef1bb6`.
